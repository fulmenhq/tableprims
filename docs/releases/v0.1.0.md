# v0.1.0

First release of tableprims, an experimental typed tabular conversion
library implemented in Rust and in pure Go, with the `tablebolt`
command-line tool. It follows the Tabular Exchange Standard, contract
revision `tabular-exchange/0.1.0`, published in
[fulmenhq/crucible](https://github.com/fulmenhq/crucible) `v0.5.1`.

## What it ships

- **Rust library (`crates/tableprims`)**: exact integers and fixed-scale
  decimals of up to 38 digits, calendar dates and timestamps kept as
  written, schema and policy documents, quantization with five rounding
  modes, rows as newline-delimited JSON, and the binary64 representation
  decision. It has no dependencies.
- **XLSX adapter (`crates/tableprims-xlsx`)**: writes a typed table to one
  worksheet. Exact numbers become numeric cells only when the stored value
  reads back as the source value; otherwise the policy refuses the value or
  writes the column as text. Types, scale and nullability are recorded on a
  hidden worksheet.
- **`tablebolt xlsx write`**: converts rows to a workbook under a schema
  and a policy, and writes a result document with input and output digests,
  per-column counts and, on a refusal, its category, rule and location. It
  never replaces an existing file, stops cleanly on SIGINT or SIGTERM, and
  can report the run through the process-run contract of 3leaps Crucible,
  telemetry only. See [docs/xlsx-write.md](../xlsx-write.md).
- **Go package (`github.com/fulmenhq/tableprims/table`)**: standard library
  only, no cgo. Reads schema and policy documents, values, quantization and
  rows, and reports every refusal as a `*table.Refusal` with its category,
  rule, row and column. It does not write workbooks and has no command-line
  tool. See [docs/go.md](../go.md).

## Conformance

Both implementations run 477 of the 639 vectors and fixtures of the crucible
release `v0.5.1`, vendored unedited and checked by digest, and meet the
expectation of every one, each at the stage where it applies. The 92
conversion result fixtures and the 70 matching vectors are not run. Results
can differ for inputs outside the vectors; the known differences are listed
in [docs/go.md](../go.md#differences-from-tablebolt-outside-the-vectors).

CI runs both on Linux x86_64 and aarch64, macOS arm64 and Windows x86_64 and
aarch64, with Rust 1.88.0 and Go 1.26.10.

With this release the two implementations are locked: a change to the shared
document, value or row behaviour, or to the vendored vectors, lands in both
and in their tests in the same pull request. Workbook writing and the binary64
decision are declared Rust-only capabilities.

## Install

- Go: `go get github.com/fulmenhq/tableprims@v0.1.0`
- Rust: the crates are not published to a registry; depend on this
  repository at the tag `v0.1.0`, or build `tablebolt` from source with
  `cargo build --release -p tableprims-cli`.

No binary or package artifact is published with this release.
