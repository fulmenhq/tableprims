# Security

tableprims is experimental and has made no release, so no version is
supported yet. How the conversion treats untrusted input and dependencies is
recorded in
[SecDR-0001](docs/decisions/SecDR-0001-untrusted-input-and-dependencies.md),
and the release trust model in [docs/security/README.md](docs/security/README.md).

Report potentially sensitive security issues privately to
[security@3leaps.net](mailto:security@3leaps.net). Include the affected version
and a minimal synthetic reproduction when available. Do not post credentials or
private data in public issues.
